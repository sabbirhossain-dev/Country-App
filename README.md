# 🌍 Country App

A modern and responsive country information web application built with React, Vite, and Tailwind CSS, allowing users to explore country information through a clean and user-friendly interface.

## 🌐 Live Demo

🔗 **Live Website:** https://country-app-two-beryl.vercel.app/


## 🛠️ Technology Stack

| Technology | Purpose |
|:---|:---|
| **React** | Building the user interface |
| **Vite** | Fast development and production build tool |
| **Tailwind CSS** | Styling and responsive design |
| **UUID** | Generating unique identifiers |

## ⚙️ Setup & Installation

Follow the instructions below to run the project on your local machine.

### 📋 Prerequisites

Before running the project, make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm

You can check whether Node.js and npm are installed by running:

```bash
node -v
npm -v
```

## Installation


### 1. Clone the Repository
```bash
git clone https://github.com/sabbirhossain-dev/Country-App.git
```

### 2. Navigate to the Project Directory
```bash
cd Country-App
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start the Development Server
```bash
npm run dev
```

### Usually, the application will be available at:
```bash
http://localhost:5173
```

### Build for Production
```bash
npm run build
```
